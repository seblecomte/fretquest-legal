# fretquest-legal

Hosted legal pages for the **FretQuest** iOS app.

Published via GitHub Pages:

- 🏠 https://seblecomte.github.io/fretquest-legal/
- 🔒 https://seblecomte.github.io/fretquest-legal/privacy
- 📜 https://seblecomte.github.io/fretquest-legal/terms

App repo: https://github.com/seblecomte/fretquest (private)

---

## Updating

Edit any `.md` file on `main`, push. GitHub Pages rebuilds in ~30-60 s.

Bump the **"Last updated"** date in the relevant file when material changes.

## Future translations

When the app ships EN + FR + ES + JA + PT-BR, the same pages will get translated counterparts:

```
/privacy           (EN, canonical for the App Store listing)
/privacy.fr
/privacy.es
/privacy.ja
/privacy.pt-br
```

Same for `/terms`.
